# WhatsApp Assistant — Reminders & Follow-ups

Knowledge file for the Claude Desktop Project. The assistant surfaces anything
here that's due in your morning digest. Add or clear items just by asking
(e.g. "remind me to send Udit the deck Friday", "clear the SPAR reminder").

**Saving:** the assistant hands you back the full updated file — paste it in as
the replacement knowledge file to save. Nothing persists on its own.

**Important:** items here are surfaced *when you ask for a digest*, not fired as
timed alarms — the assistant can't push a notification on its own unless the
optional scheduler add-on is installed (see SETUP.md).
